# Cocktail Explorer 

A React application that uses TheCocktailDB API to explore and search for cocktails.

## Features
- Live search with debouncing
- Alcoholic and non-alcoholic filters
- Cocktail images and categories
- Loading, error, and retry states
- Responsive design

## Built With
React, Vite, JavaScript, CSS, and TheCocktailDB API.

## Run Locally
1. Run `npm install`
2. Run `npm run dev`
3. Open the localhost link

## Live Website
https://cocktail-explorer1.netlify.app

## Error Testing
Click "Test Error" to simulate a failed API request and "Restore API" to reload the cocktails.
